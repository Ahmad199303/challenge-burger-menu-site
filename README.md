# Challenge Burger — Menu Site

موقع صفحة واحدة (Single Page) لمطعم **Challenge Burger** يعرض المنيو الكامل، الترويسة والدعوة للطلب، وفروع المطعم في عمّان مع روابط خرائط جوجل.

## المحتوى
- **الرئيسية (Hero):** شعار المطعم، الشعار التسويقي "Simple. Tasty. Fresh."، وأزرار للانتقال للمنيو والفروع.
- **المنيو:** تبويبات (برجر لحم / برجر دجاج / مقبلات ومشروبات) مبنية من ملف المنيو الأصلي (PDF)، بالإضافة لصور المنيو الأصلية القابلة للتكبير.
- **الفروع:** فرع شارع المدينة المنورة وفرع شارع مكة، كل واحد بخريطة مصغرة وزر "الحصول على الاتجاهات" يفتح رابط خرائط جوجل الخاص بالفرع.

## هيكل الملفات
```
index.html
assets/
  css/style.css
  js/script.js
  logo.jpg
  menu/page-1.jpg   # صفحة برجر اللحم من المنيو الأصلي
  menu/page-2.jpg   # صفحة برجر الدجاج والمقبلات من المنيو الأصلي
```

## التشغيل محلياً
الموقع HTML/CSS/JS ساكن بالكامل، يكفي فتح `index.html` مباشرة في المتصفح، أو تشغيل سيرفر بسيط:

```bash
python3 -m http.server 8080
```

ثم فتح `http://localhost:8080`.

## النشر على GitHub Pages
1. ارفع المشروع إلى مستودع GitHub.
2. من إعدادات المستودع Settings → Pages، اختر Branch: `main` والمجلد `/ (root)`.
3. الموقع سيصبح متاحاً على رابط مثل: `https://<username>.github.io/challenge-burger-menu-site/`.

## تحديث الأسعار أو الأصناف
كل صنف في المنيو عبارة عن بطاقة `menu-item` داخل `index.html` ضمن التبويب المناسب (`panel-beef` / `panel-chicken` / `panel-sides`) — يمكن تعديل الاسم، الوصف، والأسعار مباشرة داخل الوسوم.
